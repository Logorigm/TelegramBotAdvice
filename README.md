# Бот-предложка для Telegram-канала

Пользователи присылают боту в личку **фото, видео или гифки**.
Бот пересылает их модератору с кнопками **✅ Опубликовать / ❌ Отклонить**.
После одобрения контент публикуется в канал (без пометки «переслано» и без имени автора),
а автор получает уведомление о решении.

## Запуск

1. Добавьте бота в канал **администратором** с правом публикации сообщений.
2. Модератор должен один раз написать боту `/start`, иначе бот не сможет ему писать.
3. Установите зависимости и настройте конфиг:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # и впишите туда токен, id модераторов и id канала
python bot.py
```

| Переменная      | Что это                                         |
|-----------------|-------------------------------------------------|
| `BOT_TOKEN`     | токен от @BotFather                              |
| `MODERATOR_IDS` | id модераторов через запятую                     |
| `CHANNEL_ID`    | id канала (вида `-100…`)                          |

Файл `.env` в git не попадает — не публикуйте токен.
